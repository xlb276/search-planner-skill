# 搜索 / AI 工具详细对比

> 各家套餐和限额变动频繁，以下按"定位和能力"对比；执行前先确认额度以官网/客户端显示为准。

## 两大类产品

- **检索类**（秘塔、DeepSeek 网页版内置搜索、Kimi 搜索、必应/百度）：先搜索再生成，答案带引用可溯源。解决"信什么"。
- **对话类**（ChatGPT、DeepSeek、Kimi 聊天）：回答主要来自模型自身知识，搜索只是其中一项功能。解决"怎么加工"。
  - 注意：对话类不勾联网就是靠记忆答，有幻觉风险；"帮我查 XX"在检索类里自动触发搜索，在对话类里默认不触发。

## 秘塔额度细则（写 skill 决策时引用）

- 普通 AI 摘要搜索：免费，无明确每日硬限（有防刷机制，正常使用碰不到）。
- 深度搜索/深度研究：免费版一天限次（个位数，官方调过），用完等次日重置或开会员。
- AI 阅读：总结/翻译免费，长文与高级功能走会员。

## 各途径优缺点（各工具网页端，agent 选路用）

**秘塔（metaso.cn）**
- 网页版：✅ 普通搜索免费无硬限，引用逐条可点、溯源最严；❌ 无公开 API，结果页 JS 渲染 agent 的 WebFetch 抓不动 → 只能人工搜后贴结果/摘要，或用 browser-use 自动操作
- 深度搜索：✅ 一次出带引用的完整报告；❌ 免费版一天限次（个位数），用一次少一次，只给"子问题 ≥ 3"的活开

**DeepSeek（chat.deepseek.com）**
- 网页内置搜索：✅ 免费放开、能多轮追问；❌ 索引广度和时效一般，引用宽松 → 只当粗筛快查，结论要再拿秘塔/原文复核。深度思考模式（网页版免费）用于材料矛盾裁决

**Kimi（kimi.moonshot.cn）**
- 网页版：✅ 超长文档摘要招牌、搜索也免费；❌ 无自动化途径，靠人操作

**ChatGPT（chatgpt.com，需 VPN）**
- 网页版（需 VPN）：✅ 多语言归纳/报告强（含中英互转），免费版轻量模型日常够用；❌ 深度研究（Deep Research）和高级模型限次/需 Plus

**必应**
- 浏览器：✅ **盲搜、泛探索**可以直接用（没想好搜什么词也没关系），英文资料也好使；❌ 结果页对 agent 抓取不友好 → agent 侧做法是"搜索只用来找 URL，拿到 URL 后 WebFetch 抓内容"，不试图抓结果页本身

**百度**
- 浏览器：✅ 只在**明确指定**查找时用——百科条目、商品参数、论坛帖、国内官网入口；❌ **不能拿来做盲搜**，搜什么还没想清楚就换必应

**通用规律**：所有工具的搜索能力都在网页/App 端，agent 侧的检索只有"找 URL → WebFetch 抓内容"一条路；归纳这步要么 agent 自己做（材料少，默认），要么用户在网页版做（材料多）。

## 组合用法（推荐默认流程）

1. 大范围目标：DeepSeek 网页版（或 Kimi，平替按优缺点选）拆成多个中范围子问题。
2. 每个子问题 → 秘塔搜索（搜索环节无平替；子问题 ≥ 3 才开深度搜索，限次省用）。
3. 材料总结：ChatGPT 网页版整理成 agent 好取用的中间产物，推荐**目录式**：先总结所有搜索内容，再给 AI 搜索出的完整内容的目录（哪部分/哪段讲什么+来源链接）；具体形式看情况。连接不稳时 Kimi 是主场景。
4. agent 按目录成稿；材料 < 3 篇时跳过 ①③，agent 自己归纳（推荐，非硬性——看具体情况）。
5. 产出带引用的结论；未核实的单独标注。
